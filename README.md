# Website 2 — No-Scroll CV

## Project Description

This project is a personal CV website designed to present my education, skills, projects, courses, and personal information in a professional and organized layout.

The website uses a forest green, sage green, ivory, and white color theme. It includes modern cards, subtle shadows, hover effects, and animations to create an elegant appearance.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Personal introduction and profile picture
- Education and technical skills
- Personal strengths
- Projects and courses information
- Contact and GitHub profile links
- Forest green and sage green color theme
- Animated profile picture and decorative elements
- Hover effects on buttons and information cards
- Responsive layout for desktop and mobile screens
- Compact No-Scroll CV design

## Design Prompt Used

**Prompt:**

Create a professional, modern, single-page No-Scroll CV website for a Computer Science student named Fasiha Nadeem. Use a forest green, sage green, ivory, and white color palette to create a clean and elegant design.

Use HTML5, CSS3, and JavaScript. Create a top section with a personal logo, availability status, and contact link. Add a hero section containing the student's name, cybersecurity-focused title, short introduction, location, action buttons, and circular profile picture.

Create six information cards to display education, technical skills, personal strengths, projects, courses and certifications, and personal information. Use rounded white cards, subtle borders, soft shadows, green labels, and consistent spacing.

Include smooth animations such as a floating profile picture, rotating decorative circles, a pulsing availability indicator, and hover effects on buttons and cards. Use Segoe UI or Arial typography.

Make the website responsive for desktop and mobile screens. Use a two-column hero layout and a three-column information-card grid on larger screens. On mobile screens, reduce font sizes, card padding, and spacing to create a compact layout.

The main goal is to present the CV in one screen without scrolling while keeping the content readable and ensuring that important information remains visible. Use CSS variables for theme colors, organized styles, and minimal JavaScript.
